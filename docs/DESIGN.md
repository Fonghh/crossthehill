# Cross the Hill — 設計文件（MVP）

原創的多人合作越野駕駛遊戲：low-poly 立體可愛風、運送任務、用絞盤互相拉車。

## 技術
- TypeScript + Vite + Three.js + Rapier（WASM）網頁遊戲，手機（直向優先）與電腦皆可玩
- 部署：Cloudflare Pages；TURN 憑證由 Cloudflare Worker 簽發（`worker/`）

## 連線
- PeerJS（WebRTC），**開房者當主機、跑物理**（權威），其他玩家送輸入、收快照並插值
- 預設上限 8 人（`src/config/game.ts` 可調），建議電腦開房
- **主機轉移**：主機斷線（或離開）時，剩下的玩家依加入順序由第一位接手，從最後一個快照重建世界（車子姿態與速度、繩子、任務進度、標記），其他人自動連到新主機。新主機會在舊房號釋放後接手原房號，讓邀請連結繼續有效
- **斷線保留**：任何玩家斷線，車子原地保留 45 秒（名牌顯示「斷線」），期間重連可以接回原車；斷線玩家不影響送達判定
- 心跳偵測：客戶端 3 秒收不到快照、主機 5 秒收不到輸入，就判定斷線（WebRTC 本身回報斷線很慢）
- 語音交給 Discord / LINE（遊戲內不做語音）

## 流程
暱稱 → 開房 / 輸入房號（可分享連結 `?room=XXXX`）→ 選車與顏色（附特性說明）→ 隨時加入，出生在主機附近

## 車種
| 車 | 特性 |
|---|---|
| 小吉普 | 平衡、輕巧、重心低 |
| 大腳卡車 | 馬力與絞盤拉力大、輪大越障強；重心高易翻、慢 |

- 半擬真物理，不加防翻滾（參數保留，預設 0）
- 引擎以齒比建模（自動排檔），預留手動檔／4L 低速四驅
- 所有手感參數集中於 `src/config/vehicles.ts`，`?debug` 開啟即時調參面板

## 互助
- 每車一條絞盤繩，最長 30m；鬆不施力、繃緊有拉力；可收繩；可掛車／樹／大石；可多車串接
- 車與車有碰撞
- 操作：按住勾繩鈕出準心（自動吸附）→ 拖曳換目標 → 放開射出 → 按住收繩、✕ 斷開
  - 電腦：E 按住 + 滑鼠，Q 斷開；手把：LB + 右搖桿，B 斷開

## 任務
- 每車載貨（增重、不會掉）。全隊進入終點範圍＝送達一次，抽下一個終點（難度漸增）
- 顯示送達次數與單趟時間；無失敗條件

## 自救
- 原地翻正（冷卻 5 秒）；回到上一個送達點；泡水 3 秒自動回送達點；不提供傳送到隊友

## 地圖
- 固定種子程序生成，約 1km × 1km 島嶼
- 土路、草地、岩石、泥地、淺溪、陡坡、稜線、樹林

### 地形一致性原則（最重要）
1. 顯示網格與物理碰撞由**同一份頂點與索引**產生（trimesh），三角形完全相同
2. 不用隱形牆、不用方塊近似；岩石碰撞＝顯示用的凸包本身；樹只有樹幹有碰撞
3. 小裝飾（草叢、小石、落葉）無碰撞且做得夠小
4. 輪胎用**球形掃掠**偵測地面，不卡三角形接縫、能自然爬上石頭邊緣
5. 地面平滑著色、岩石保留稜角；格距 2m
6. 材質（泥、岩、草、路、水深）存在頂點上，畫面顏色與物理抓地力用**同一套插值**
7. `npm run analyze-terrain` 產生坡度熱度圖並檢查主要道路坡度

## 介面（直向）
- 左下搖桿（轉向）；右下油門、煞車/倒車、勾繩、喇叭、重置
- 右上羅盤 + 旋轉小地圖，點擊展開北朝上大地圖，點大地圖放標記（10 秒）
- 左上傾斜儀；上方任務資訊

## 畫面與音效
- 程式生成 low-poly 模型（之後可換 CC0 素材）、高角度追尾鏡頭、雙指／滾輪縮放
- 依幀率自動畫質（目標 30fps+）
- Web Audio 合成：引擎、絞盤、繩子、喇叭、碰撞
